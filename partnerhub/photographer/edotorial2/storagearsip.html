Awan Edotorial

Akses dan temukan file foto & video hasil sesi kamu yang tersimpan di cloud kami.

Contoh: Dinda_Prewedding_2025

Buka cloude.kutemo.id
Panduan Mencari File
1

Dapatkan Kode Sesi

Setelah sesi foto selesai, tim Edotorial akan mengirimkan kode sesi melalui WhatsApp. Kode ini unik untuk setiap klien.

2

Ketik di Kolom Pencarian

Masukkan kode sesi atau nama kamu di kolom pencarian di atas, lalu tekan Cari. Kamu akan diarahkan ke halaman file kamu di cloude.kutemo.id.

3

Unduh File Kamu

Pilih foto atau video yang ingin diunduh. File tersedia selama 30 hari setelah pengiriman kode sesi.

4

File Tidak Ditemukan?

Pastikan kode sesi benar. Jika masih tidak muncul, hubungi kami via WhatsApp — tim kami siap membantu.

File disimpan di cloude.kutemo.id dan hanya dapat diakses menggunakan kode sesi yang dikirim oleh tim kami. Jaga kerahasiaan kode kamu.
